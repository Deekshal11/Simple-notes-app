# Simple Notes App

## Project Overview
Simple Notes App is a Python Flask web application deployed on an AWS EC2 Ubuntu server. It allows users to add and view saved notes.

## Technologies Used
- AWS EC2
- Ubuntu Linux
- Python
- Flask
- HTML and CSS
- Git and GitHub
- Nginx

## Features
- Add notes through a web interface
- Display saved notes
- Health-check endpoint
- Cloud deployment using AWS EC2

## Deployment
The application runs on an Ubuntu EC2 instance. Nginx acts as a reverse proxy and forwards web requests to the Flask application running with Gunicorn.
